Playlet 💿

Play songs on any DLNA server from the browser, no app installs.

javascript:import("https://est.github.io/playlet/loader.js")
  1. Copy the code above (It's called a bookmarklet)
  2. Save it as URL to your browser bookmark. For Chrome:
    1. Hit the ☆ on the right side of address bar.
    2. Click "More" on the popup
    3. Paste the code as the URL
    4. Give it another name if you like
  3. Open DLNA page (usually http://NAS-IP:8200/).
  4. Click the bookmark. Browse tree with +/-, queue tracks, play.
